Nova D1 Simulator

The real UI, in your browser.

This runs the actual Nova D1 interface — the same code that drives the device — live from the repo. No hardware needed. Turn the encoder and press the buttons to explore every menu and app. Hardware features show “not found” (there are no real chips in a browser); everything else is the genuine experience. Drop a real Flipper Zero .ir, .sub or .nfc file on the device and watch the same codecs the hardware uses parse it and show it on the screen.
