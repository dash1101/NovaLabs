Privacy

Privacy

The short version: NovaLabs doesn’t track you, doesn’t run ads, and doesn’t sell anything about you. Here’s the longer version.

Last updated: October 2026

Who we are

NovaLabs is an independent hardware and software lab run by dash, based in the United States. This policy covers the NovaLabs website (novalabs.app and its pages), the small web tools we host, and the RPCortex operating system you install on your own hardware. The RPCortex site (rpc.novalabs.app) has its own, more detailed policy.

The website

  • No analytics, no cookies, no tracking pixels, and nothing stored in your browser. The site is static; there is nothing watching what you click. Fonts and scripts are served from the site itself, so opening a page does not send your address to a font or script host.
  • Standard server logs. The site is served by GitHub Pages, which may record routine request data (such as your IP address and browser type) for security and reliability. We don’t build profiles from it, and GitHub’s own privacy statement applies to what it records.
  • The Nova D1 simulator. When you open the simulator, your browser downloads the Python runtime from jsDelivr (cdn.jsdelivr.net) and the Nova D1 module files from GitHub (raw.githubusercontent.com). Those are ordinary requests to those services, and their policies apply. Files you drop on the simulator are read in your browser and are not uploaded anywhere.
  • Links out. Some buttons take you to GitHub, Instagram or Discord. Once you’re there, those companies’ own privacy policies apply.

The tools we host

ytdl-UI (yt.novalabs.app) takes a link you paste and fetches that media for you to download. It doesn’t require an account, and it isn’t built to keep a history of what you grab. Please only use it for content you have the right to download.

RPCortex & the Nova D1

RPCortex runs entirely on your device. Your accounts, password hashes and saved Wi-Fi networks are stored locally on the device’s own flash; none of it is sent to NovaLabs. A few honest notes for owners:

  • Saved Wi-Fi passwords are sealed, not unbreakable. On RPCortex v2 they are encrypted under a key unique to the device before they are written down, which protects a copy of the settings file or a backup. Microcontrollers have no secure enclave, so someone holding the whole flash can still recover them. Treat the device like a key. (On the older MicroPython v1 they are stored in plaintext.)
  • Network features reach out only when you use them. Commands like wget, ntp sync or pkg install connect directly to the service you point them at; NovaLabs isn’t in the middle.
  • Over-the-air updates on v2 fetch release files from GitHub when you run them. That’s a normal web request, and no device identifiers are sent beyond what any web request carries.

Children

NovaLabs’ projects aren’t directed at children under 13, and we don’t knowingly collect information from them.

Changes

If this policy changes, the date above changes with it. Material changes will be noted on this page.
