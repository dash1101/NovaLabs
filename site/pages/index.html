Operating system

RPCortex

A full, multitasking operating system for the Raspberry Pi Pico family, written in C++ with no interpreter: a real shell with pipes and scripting, user accounts, a package manager, Wi-Fi and over-the-air updates, and on the RP2350 a sandbox for packages, so a bad one costs a command rather than the device. v2 “Vela II” is in beta. Flagship hardware · In active development

The Nova D1

A pocket multi-tool for security research, radio tinkering and poking at hardware, built from off-the-shelf modules. It costs about $20 to start, and roughly $55 with the radios.

The Nova D1 is a package for RPCortex v2 “Vela II”, the multitasking OS I write for the Pico, in C++. Put the OS on a Pico 2 W, run pkg install novad1, and it brings up the Nova GUI with its background services. Both the OS and the package update over Wi-Fi. The package runs from its own flash slot rather than from RAM, which keeps most of the Pico’s memory free. The MicroPython build for RPCortex v1 is still around, and the build progress page tracks it.
