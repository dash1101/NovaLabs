Operating system

RPCortex

A full, multitasking operating system for the Raspberry Pi Pico family, written in C++ with no interpreter: a real shell with pipes and scripting, user accounts, a package manager, Wi-Fi and over-the-air updates, and packages that run in a sandbox so a bad one costs a command rather than the device. v2 “Vela II” is in beta. Flagship hardware · In active development

The Nova D1

A pocket multi-tool for security research, RF tinkering, and hardware exploration — built entirely from off-the-shelf modules in a 3D-printed shell, for about $20 to start and roughly $55 with the radios. No custom PCB, no factory, no $200 price tag.

The Nova D1 doesn't run rigid, single-purpose firmware. It is a package for RPCortex v2 “Vela II”, a genuine multitasking OS written in C++: put the OS on a Pico 2 W, run pkg install novad1, and it brings up the Nova GUI with its background services. The package runs from its own flash slot instead of being copied into RAM, and over-the-air updates keep the OS and the package current. The MicroPython build for RPCortex v1 is still around and is tracked on the build progress page.
